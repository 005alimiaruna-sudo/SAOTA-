# SAOTA Venture 💧

> Nigeria's Premier Water Supply & Distribution Company Website

## Tech Stack
| Layer | Technology |
|-------|-----------|
| Frontend | HTML5, CSS3, Vanilla JavaScript |
| Backend | Python 3.11 + Flask |
| Server | Gunicorn (WSGI) |
| Hosting | Railway |
| Repo | GitHub |

## Deploy to Railway
1. Push to GitHub
2. Connect repo on railway.app
3. Set `FLASK_ENV=production`
4. Deploy ✅

## Local Setup
```bash
pip install -r requirements.txt
python app.py
```
Open http://localhost:5000
